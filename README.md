# Brazy Toolkit — updates

Update channel for the Brazy Toolkit desktop app: the hub for Brazy Clothing Manager (clothing, skate and patch textures
for ReSkate Studio), Brazy Logo Maker and Brazy Video Editor.
The app checks `latest.json` on start-up and offers the `.rsupd` file it points to (a small zip with only the changed
toolkit / model files).

Current version: **8.15.0**
